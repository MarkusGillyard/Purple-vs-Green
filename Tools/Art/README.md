# Battlemage source

The Blender script generates the editable geometry and armature. The Unreal commandlet imports the mesh and skeleton and creates the armor and spell materials. The import project enables Python only for these authoring commands.

From this directory, with Blender 5.2.2 and the project's UE 5.8.4 installation:

```bash
blender -b --factory-startup --python battlemage.py -- "$PWD/Battlemage.fbx"
PVG_BATTLEMAGE_FBX="$PWD/Battlemage.fbx" "$PVG_ENGINE/Engine/Binaries/Linux/UnrealEditor-Cmd" \
  "$PWD/ArtImport.uproject" -run=pythonscript "-script=$PWD/import_battlemage.py" \
  -nullrhi -unattended -stdout
```

Review the generated assets in the import project's Content directory before updating the corresponding files in the game project. The source FBX is regenerated by Blender. The shipped mesh uses four material slots, and the two teams share its skeleton and pose logic.

## Casting gloves

The Blender script generates mirrored leather gloves with layered bracers and the
two finger meshes shared by both hands. The Unreal importer verifies the
forward axis and material slots. The game articulates the knuckles and the
middle joints during casting and warding.

```bash
blender -b --factory-startup --python gauntlets.py -- "$PVG_GAUNTLET_ART"
PVG_GAUNTLET_ART="$PVG_GAUNTLET_ART" "$PVG_ENGINE/Engine/Binaries/Linux/UnrealEditor-Cmd" \
  "$PWD/ArtImport.uproject" -run=pythonscript "-script=$PWD/import_gauntlets.py" \
  -nullrhi -unattended -stdout
```

Review the imports before copying the casting meshes and material to the game
project.

## Meridian environment

The environment scripts generate the ridge, crystal, reeds, ashlar, and a seamless
masonry texture containing mineral color, roughness, and height. The import commandlet
builds the triplanar masonry and vertex-color terrain materials. Generate into a
project-owned scratch directory with Python 3 and Pillow, and use the same Unreal
import project as above.

```bash
mkdir -p "$PVG_MERIDIAN_ART"
python3 meridian_surface.py "$PVG_MERIDIAN_ART"
blender -b --factory-startup --python meridian_meshes.py -- "$PVG_MERIDIAN_ART"
PVG_MERIDIAN_ART="$PVG_MERIDIAN_ART" "$PVG_ENGINE/Engine/Binaries/Linux/UnrealEditor-Cmd" \
  "$PWD/ArtImport.uproject" -run=pythonscript "-script=$PWD/import_meridian.py" \
  -nullrhi -unattended -stdout
```

Review the imported assets before copying the Meridian meshes and updated materials to
the game project.

## Casting motion samples

Download KayKit Character Animations 1.1 Free from the publisher linked in the
[asset ledger](../../Docs/Assets.md). Extract the medium ranged-combat FBX and
regenerate the normalized hand trajectories with Blender 5.2.2.

```bash
blender -b --factory-startup --python-exit-code 1 --python Tools/Art/extract_cast_motion.py --   /path/to/Rig_Medium_CombatRanged.fbx Source/PurpleVsGreen/KayKitCastMotion.h
```

Run this command from the repository root. The game blends these samples into its
existing articulated rig and plays them against the accepted cast's release time.
